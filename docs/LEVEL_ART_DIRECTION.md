# deeper and deeper：关卡与美术执行稿

日期：2026-10-21。状态：0.4核心已实施，真人可读性/平衡待验收。关联：[当前两周排期](SHORT_TERM_ROADMAP.md)与[实施证据](IMPLEMENTATION_REPORT.md)。代码基线：`7211a3d`。下文规格中的目标时长和观察者指标仍待实测。

## 审美定调：王国地下，火光逐渐远去

保留标题里的城堡、铁链、石砌与中世纪纹理像素。第一层仍能看见王国秩序的残迹；第二层空间更破损、仪式意味更强，但战斗区域必须清楚。每次下潜都有新的空间关系、地标和站位问题。

实机观察来自 `docs/review/mvp-title.png`、`mvp-game.png`、`mvp-boss.png`：标题层次丰富；游戏地面砖缝与墙面同样抢眼，人物小且轮廓容易被纹理吞没；两层同样横向三房，下潜仅用小楼梯图标。静态图不能证明动态打击感、时长与帧率，相关判断交给试玩。

## 第一层：封土回廊

主题：灰褐石、暗酒红织物、烛金；宽阔、规整、可预判。目标：学会换弓、横移、看前摇，然后第一次决定是否继续下降。

```mermaid
flowchart LR
    A[入口补给庭\n首箱二选一] --> B[断旗交战厅\n左右绕柱与拆群]
    B --> C[绞盘守卫厅\n精英考试]
    B --> S[可选：封印侧室\n可见守卫和补给]
    S --> C
    C --> W[下潜井\n撤离 / 普通下潜 / 井契]
```

| 空间 | 遭遇与操作目的 | 奖励/信息 | 目标节奏 |
|---|---|---|---|
| 入口补给庭 | 无主动敌人；从护栏后看到井壁、垂链 | 必经首箱，现有两弓二选一；只显示本次必要操作 | 20–40 秒；30 秒内知道向哪里走 |
| 断旗交战厅 | 两组错开敌群，先分散再可排线；柱子不构成狭窄死角 | 一段破旗/烛台朝主路形成地标 | 60–90 秒；引怪不一次拉满全层 |
| 可选封印侧室 | 门外可看到宝匣及守卫；用现有怪重新分配，不增加精英类型 | 本层原第二个箱/补给移到这里；不再顺路白拿 | 往返 30–60 秒；不影响出口解锁 |
| 绞盘守卫厅 | 守门精英+可独立处理的少量护卫；门洞后留闪避空间 | 精英死亡仍掉现有装备，井口解锁、链轮转动 | 60–90 秒 |
| 下潜井 | 无新敌人；让玩家在安全区域读收益与风险 | 显示生命、药水、当前分、下一层与契约效果 | 15–30 秒 |

侧室回环优先接回守卫厅前的安全段，禁止出口直接落到精英攻击半径。D3 若回环清理、相机或碰撞超时，改为单入口支路。

## 第二层：无灯圣所

主题：蓝灰湿石、氧化铜绿、骨白遗骸；第一层同一根链从上方垂下。目标：以折线路线改变视线，用排线/侧移的选择检验装备，最后在完整平台挑战 Boss。

```mermaid
flowchart LR
    A[落井平台\n安全观察与同一根垂链] --> B[断桥外廊\n折线主路与直线射击窗口]
    B --> C[井环圣所\n完整平台上的Boss]
    A --> S[可选：遗骨祈祷室\n较紧凑遭遇与装备匣]
    S --> B
    C --> R[通关结算]
```

| 空间 | 遭遇与操作目的 | 奖励/信息 | 目标节奏 |
|---|---|---|---|
| 落井平台 | 无敌人贴出生；镜头展示井壁和下一段暖色路标 | 明确生命/药水没有自动回满；契约状态清楚 | 10–20 秒 |
| 断桥外廊 | 连接段折线，交战段宽直；骷髅与哥布林错位，引导排线 | 有护栏、碎边和远处灯火；不能跳跃/坠落 | 60–100 秒 |
| 可选遗骨祈祷室 | 消耗补给换终战装备；入口能观察到风险 | 本层原有奖励重分配至侧室；不承诺未实现的新装备 | 往返 30–60 秒 |
| 井环圣所 | Boss 复用重击与冲刺；中央可走空间完整，装饰与深井靠边 | 接近才显血条；战后按原流程通关 | 90–150 秒，待实测 |

“井环”指环境构图，不要求 Boss 或敌人沿环形狭路寻路。深井不可进入、无跌落伤害；侧边完整地台承担战斗。若地图纵向扩展增加相机成本，就在原地图尺寸内做折线，但两层必须有不同房间位置与视线。

## 空间与实现约束

- 以当前 1280×720 视口、Player 26×26 碰撞为基线。普通门洞通行宽度起点 160–180 像素；战斗平台至少能容纳一次约 140 像素翻滚加安全余量。数值是白模起点，按实际角色与镜头校准。
- 碰撞、贴图墙脚和可走区域同源；井沿、断桥与护栏全部有一致边界。镜头必须显示正在蓄力的主要攻击者，避免屏外冲刺进入。
- 现有 `enemy.gd::_chase` 是直线追逐，没有绕障导航。D2/D3 将遭遇控制在本房间，跨房进入需视线与范围校验；所有敌人出生点到主要交战区必须有直接可走通路。
- 不把静态柱群排成 U 形陷阱；Boss 平台不放阻断其直线路径的中央大井。实测出现卡墙，优先调整障碍与敌位，再考虑局部避障，不能悄悄扩大成导航重构。
- 两套手工配置共用绘制/碰撞构件；每个主房有独特地标，方向提示不只依靠迷你地图。每层三个主房与一个支房不是扩充敌人数量的理由。
- 井契裂隙由统一契约状态创建，主路至少两处安全站位；与 Boss 冲刺不形成必中的夹击。生命周期挂在当前层内容下，换层统一释放。
- 用生命与药水维持局内资源压力；不新增氧气、饥饿、装备耐久或全局倒计时。

## 美术执行规格

| 项目 | 执行规则 | 验收 |
|---|---|---|
| 像素尺度 | 沿用角色源像素风；新环境组件统一颗粒，nearest 采样、整数对齐 | 移动时无明显纹理抖动，不拉伸单块石砖去填整个房间 |
| 地面 | 3 个低对比完整石板变体+1 个裂损变体，战斗中心磨平，细节集中在边缘 | 箭、角色脚下轮廓与预警比砖缝醒目 |
| 墙体 | 墙冠、迎人墙面、脚线阴影分层；4 个转角模块与1个拱门 | 远看能区分不可走墙体和普通地砖 |
| 井口 | 石沿、绞盘、垂链、两层衰减井壁、底部冷光，共用一套主体 | 第一层井口与第二层垂链能被认作同一地点 |
| 第一层 | 深墨 #14151D、灰褐 #474039、暗酒红 #672D39、烛金 #D6A34A | 主路暖灯，奖励金，危险仍红色+轮廓 |
| 第二层 | 墨蓝 #17212B、湿石 #374951、铜绿 #54867B、骨白 #D8D2C4 | 不看层名也可从结构与材质辨认 |
| 角色 | 保留动画；统一脚底基线、接地影、轮廓和闪白 | 不靠高亮整块地板来衬角色，敌人不会被装饰遮住 |
| UI | 暗皮革/暗金属面板，铜色细边，骨白文字；有暗底的目标/提示 | 1280×720、1920×1080 文本不重叠，不把石墙纹理平铺到每个按钮 |
| 危险 | 红色加形状轮廓、蓄力与生效变化；命中边界与预警一致 | 去掉颜色也能辨认范围和即将生效的时机 |
| 效果 | 开箱、精英死亡、链轮启动、下潜各一个主要反馈 | 震动/闪烁可关闭；普通命中不抢 Boss 招式的反馈等级 |
| 声音 | 弓弦/命中/危险/确认优先，风声与链条声居后 | 关掉背景音仍能听清攻击与交互；不在同一时刻堆满音效 |

UI 不跟随环境降低像素分辨率；中文必须清楚。字体以实际打包结果验证，若需要随包字体，在落地时记录许可与来源。新增素材继续登记 `assets/README.md`，保留已有署名。

## 五张验收图与一段实机

1. 第一层入口：玩家、首箱、主路方向、远处井口意象。
2. 第一层交战：能看出快射绕行与穿骨排线的空间。
3. 下潜井口：井壁/垂链与风险收益信息在同一个场景中。
4. 第二层绕井：同根链、不同走向与冷湿材质，安全边界清楚。
5. Boss 预警：Boss、完整跑位平台、招式范围及至少一条可走安全方向。

统一在 1280×720、同一角色缩放截取；另外核对 1080p 界面。邀请 3 名观察者在 3 秒内指出玩家、通路、交互点并区分两层。截图过关后仍需完整移动、拉怪、换层、死亡与重开的实机验证。

90 秒连续录屏建议依次展示：入口选弓 → 一组可读战斗 → 井口取舍 → 第二层地标与 Boss 攻击；不能仅用镜头移动展示空场景。

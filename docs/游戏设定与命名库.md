# 《Darker and Darker》游戏设定与命名库(产品素材)

> 版本:v0.1 | 更新日期:2026-08-04
> 用途:游戏世界观设定 + 未来武器/装备/职业/怪物/技能专属命名库(产品层面素材)
> 原则:**全部名称原创,规避 WotC(D&D)Product Identity**,风格参考但不复制。

---

## 1. 版权规避总则(最重要,先读)

依据 D&D 官方 OGL/SRD 文件,Wizards of the Coast 的 **Product Identity** 不可用于商业游戏,包括:

**⚠️ 禁用的 D&D 专有怪物/种族名(含中文译名):**
- beholder / 眼魔、gauth
- mind flayer / illithid / 灵吸怪 / 夺心魔
- displacer beast / 移位兽
- githyanki / githzerai / 吉斯人
- yuan-ti / 蛇人(指 D&D 设定)
- carrion crawler / 尸魔虫
- tanar'ri / baatezu(恶魔系族名)
- umber hulk / 铜筋铁骨怪

**⚠️ 禁用的 D&D 战役设定与地名:**
- Forgotten Realms / Faerûn / 被遗忘的国度、Underdark / 幽暗地域、Sigil、Thay、灰鹰 Greyhawk、艾伯伦 Eberron、鸦阁 Ravenloft 等

**⚠️ 禁用的专有法术/物品名(以人名命名的):**
- Mordenkainen's ×××、Tasha's ×××、Bigby's ××× 等一切"人名+物品/法术"形式

**✅ 可以放心用的(SRD 开放内容 / 通用语料):**
- 通用西幻词汇:剑/弓/箭/盾/甲/药水/卷轴/火球/闪电/治疗/亡灵/哥布林/骷髅/巨龙/精灵/矮人(作为通用种族泛称,不套用 D&D 设定细节)
- 规则机制类:基础属性、骰子机制、职业泛称(战士/法师/游侠为通用词)
- 最新 SRD 5.2 已发布为 **CC-BY-4.0**,但其中仍排除商标怪物与部分职业——**本项目作为独立游戏,一律使用自创名称,不引用任何 D&D 专有名词**,这是最安全的路径。

**命名纪律:** 任何新增名称先过一遍上面的禁用清单;拿不准的词宁可换一个原创名。

## 2. 世界观背景设定(原创)

### 2.1 世界
- **世界名:埃尔德隆(Eldron)** —— 一片被"永夜"笼罩的古老大陆
- **核心灾难:永夜裂隙** —— 千年前"天穹崩裂",地心裂开一道吞光的深渊,黑暗自裂隙涌出,腐蚀了大陆的地底

### 2.2 地牢:暮色迷宫
- 玩家探索的**多层地牢**统称"**暮色迷宫(The Dusk Labyrinth)**",是远古"秘银文明"的遗迹
- 迷宫按深度分层:**浅层(灰烬回廊)→ 中层(霜语墓穴)→ 深层(血渊)→ 最深处(永夜之心)**;越深怪物越强、遗物越珍贵
- 每一层都有独立主题:石厅、墓穴、熔岩裂谷、冰窟、腐沼、圣殿废墟

### 2.3 势力(未来剧情素材)
| 势力 | 定位 |
| --- | --- |
| 曙光公会 | 玩家所属,探索迷宫、回收遗物的冒险者组织 |
| 暗裔教团 | 崇拜裂隙黑暗的反派,企图打开更深层 |
| 灰烬骑士团 | 守卫迷宫入口的古老骑士团 |
| 秘银议会 | 铸造"秘银遗物"的远古文明后裔(知识型势力) |

### 2.4 力量体系
- **元素系**:灼焰 / 霜寒 / 雷鸣 / 蚀毒 / 暗蚀 / 圣辉(六系,用于词条与技能命名)
- **遗物等级(品级)**:白·凡铁 → 绿·精良 → 蓝·稀有 → 紫·史诗 → 橙·传说(对应命名前缀与配色)

## 8. 命名生成规则(可扩展词库)

**公式:前缀(材质/来源)+ 类型词(词根)+ 可选后缀(特性)**

| 前缀(来源/材质) | 类型词(词根) | 后缀(特性词条) |
| --- | --- | --- |
| 铁 / 钢 / 黑铁 | 弓 / 剑 / 匕首 | 逐日 / 裂空 |
| 秘银 / 星陨 | 法杖 / 权杖 / 圣典 | 霜华 / 雷啸 |
| 龙牙 / 龙鳞 | 战锤 / 长枪 / 巨剑 | 毒牙 / 噬血 |
| 月辉 / 晨光 | 盾 / 甲 / 链甲 | 贯穿 / 迅捷 |
| 血铸 / 烬燃 | 戒指 / 护符 / 徽章 | 守护 / 圣辉 |
| 影纹 / 永夜 | 药剂 / 卷轴 / 圣物 | 暗蚀 / 回响 |

**示例(按公式现场生成):**
- 星陨 + 长枪 + 雷啸 = **星陨雷啸枪**
- 血铸 + 匕首 + 噬血 = **血铸噬血刃**
- 晨光 + 圣典 + 回响 = **晨光回响圣典**
- 永夜 + 巨剑 + 暗蚀 = **永夜暗蚀巨剑**

**品级 → 命名风格建议:**
- 白:朴素直白(材质+类型,如"铁剑")
- 绿/蓝:加一个特性词(如"霜华重剑")
- 紫:两个词 + 气势(如"血月之吻")
- 橙:**主名·副名**格式,带史诗感(如"龙鸣·渊光之弓")

**落地建议:** 新物品在 `item_data.gd` 增加工厂函数时,`item_id` 用英文拼音/意译(如 `moonbow`),`item_name` 用本库中文名;存读档不受名称改动影响(`item_id` 才是稳定键)。

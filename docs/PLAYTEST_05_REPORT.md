# 0.5实施与验证记录

日期：2026-10-21。工作区尚未提交/推送；0.4报告保留历史结论。

## 已实现

J按住连续普攻，K连射、L疾射、空格闪避；聊天H、旧技能面板P。HUD四键卡、指南、包内说明同步。

三类怪物混编，曲线加速追击、锁向预警和落空恢复。受击立即持续仇恨，普通怪能追出房间与初始索敌半径。Boss免疫时被攻击也警觉，玩家场外不能伤害本体，入场锁门。

Boss半血锁定阈值，1.6秒转场后生成四根移动飞行悬柱。全破后恢复受伤，二阶段冲刺/重击/三路散射节奏加快。悬柱不产生普通击杀、分数或掉落保底。散射预警与实际射向一致，锁向后可侧移躲避。

关卡新增双入口中央掩体、绕侧翼侧室，以及远程上路/冲锋补给下路的选择，在井缘重新汇合。详见[关卡设计](LEVEL_DESIGN_05.md)。仍为两层、六装备、一个井契。

- 真实输入测试通过：J持续普攻无蓝耗，K/L技能、模态安全、Boss HUD。
- 战斗测试通过：三类怪物、不同时间步加速、真实弹体/墙体/无敌帧、阈值/四柱去重/破盾/锁向散射、暂停/重开/换层。
- 真实650像素区外箭击触发仇恨，130物理帧追出区块；拉远到1400像素继续60帧仍追击。取消回家不压制仇恨。

- 两层26×26真实碰撞体通行通过；掩体追击实验600帧后距玩家27像素。
- 原生D3D12在720p/1080p完成截图并正常退出，包含新遭遇、四柱和二阶段散射。

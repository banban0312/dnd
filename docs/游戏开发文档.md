## ⚠️ 重要开发注意事项(改代码前必读)

> 以下约定与坑是开发中必须牢记的,修改相关代码前先看这里。详见各小节正文。

1. **存档路径——发布前必改(最重要)**
   当前存档写在 `res://save/save.cfg`(项目目录,开发期可写、方便调试)。**导出发布后 `res://` 是只读的,存档会静默失败**。正式版发布前必须把 `scripts/save_manager.gd` 顶部的 `SAVE_PATH` 常量改回 `user://save.cfg`(或 `OS` 可写路径),目录创建逻辑(`SAVE_DIR`)跟随修改。不要忘记!
2. **物理层命名(禁止裸写数字)**
   `project.godot` 的 `[layer_names]`:layer_1 = `world`(玩家身体/墙/掉落物)、layer_2 = `enemies`、layer_4 = `arrows`。新增物理对象时按语义使用,敌人碰撞层统一用 `Spawner.ENEMY_LAYER` 常量。
3. **数据驱动(改数值只动一处)**
   - 敌人参数唯一数据源:`scripts/enemy_data.gd`(EnemyData.TYPES)
   - 物品/装备:`ItemData` 工厂函数 + `item_id` 稳定标识(存档用,**勿改名**,否则旧档读不出来)
   - 动画资源统一走 `AnimFactory`(anim_factory.gd)
4. **组件通信禁止反模式**
   宝箱/存档点/敌人向上通信一律用信号(`potion_requested` / `respawn_requested` / `drop_requested`),由 `main.gd` 监听;**禁止 `get_parent().has_method()` 反向调用**(已全部清理,新增组件不得复辟)。
5. **存档行为注意**
   玩家出生点 = 中央房间中心 = 存档点,开局会自动保存一次(正常行为,不是 bug);这保证"继续游戏"菜单始终可用。
6. **命名与版权纪律**
   新增职业/武器/装备/怪物/技能命名,一律以 `docs/游戏设定与命名库.md` 为唯一素材库;**禁止使用 D&D(WotC)Product Identity 专有名词**(眼魔/灵吸怪/夺心魔/移位兽/吉斯人/蛇人及被遗忘的国度等设定名,完整禁用清单见命名库 §1)。命名风格参考但不复制,拿不准就自创。

## 2. 设计愿景与核心循环

**愿景**:玩家扮演不同职业的冒险者,深入黑暗地牢,在探索与战斗的循环中不断变强,挑战更深层的地牢。

**核心循环**:

进地牢 → 探索战斗 → 拿奖励 → 升级(解锁技能系统,提升角色功能)→ 挑战更深处

> 说明:当前版本实现地牢探索基础与游侠动作(移动、射箭、技能、奖励、成长、存档),完整数值与更多内容在后续阶段完善。

## 4. 角色与职业系统

### 4.1 职业

当前实装:游侠。战士(原方案)搁置,魔法师列为后续规划。

| 职业 | 定位 | 武器 | 技能 |
| --- | --- | --- | --- |
| 游侠(当前) | 高移速、远程灵活 | 游侠短弓 | Q 三连发、E 拉弓加速 |
| 战士(搁置) | 高血量、近战肉盾 | 剑 + 盾 | Q 加速、E 回春(搁置) |
| 魔法师(后续) | 低血量、高法术输出 | 待定 | 待设计 |

职业差异体现在:基础属性不同 + 专属职业技能不同。

### 4.2 属性

基础属性:

| 属性 | 说明 |
| --- | --- |
| 血量(HP) | 归零则死亡,回到存档点 |
| 蓝量(MP) | 限制技能使用频率(普攻不耗蓝) |
| 移速 | 角色移动速度 |

后续可扩展:攻击力、防御、暴击等。

### 4.3 等级与经验

- 通过探索(开宝箱、击杀敌人)获得经验
- 升级获得属性提升与技能点
- 技能点用于解锁 / 强化职业技能

### 4.4 技能系统

- 升级解锁技能,技能提升角色功能(攻击、生存、机动)
- 技能消耗蓝量,蓝量限制技能使用频率(普攻不耗蓝)
- 职业对应不同技能树
- 游侠(当前):
  - Q 三连发:快速连射 3 支箭(占位小方块箭矢)
  - E 拉弓加速:3 秒内攻击频率(拉弓速度)大幅提升

### 4.5 装备与背包

- 装备:武器、防具等,改变属性或提供功能;占用独立的角色装备格子,不与快捷栏混用
- 背包:管理掉落物与装备
- 快捷栏:3 格,仅用于掉落消耗品
- 掉落物(初版):红药水(生命值直接回满)、蓝药水(蓝量直接回满)
- 掉落来源:敌人与宝箱;掉落机制:概率掉落

| 敌人 | 特征(待定) |

## 17. 地图系统(阶段一·大型地图)

### 17.1 结构

- 由固定大小箱庭(房间)组成的网格地图,当前默认 3×3 个房间、每间 960×720,总尺寸 2880×2160
- 相邻房间共享边墙随机开口(门口宽 110px),所有内部边均开门,保证地图全连通
- 房间四周为石墙(40px 厚),视觉与碰撞一体

### 17.2 随机路障

- 每个房间随机生成 2~5 个路障,类型随机:石柱(48×48)、横向墙块(120×40)、竖向墙块(40×120)
- 路障放置使用拒绝采样:自动避开门口通道、房间边界、出生点区域,且相互保持间距

### 17.3 生成器脚本

`scripts/map_generator.gd` 导出参数:

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `room_size` | (960, 720) | 单间箱庭尺寸 |
| `grid_cols` / `grid_rows` | 3 / 3 | 地图行列数 |
| `wall_thickness` | 40 | 墙体厚度 |
| `door_width` | 110 | 门口宽度 |
| `min_obstacles` / `max_obstacles` | 2 / 5 | 每间路障数量范围 |
| `obstacle_margin` | 70 | 路障距墙最小距离 |
| `chest_chance` | 0.7 | 每间生成宝箱概率 |
| `enemy_points_per_room` | 4 | 每间敌人出生点数量 |
| `rng_seed` | 0 | 0=每次随机;填固定值可复现地图 |

生成结果(供主场景使用):`player_spawn`、`save_point_pos`、`enemy_points`、`patrol_targets`、`chest_points`,以及调试数据 `wall_segments`、`obstacle_rects`、`door_centers`。

### 17.4 主场景集成

- 玩家节点挂载 `Camera2D`,跟随并限制在地图范围内
- 固定巡逻敌人(2 哥布林 + 2 骷髅)由生成器分配到安全点并配置巡逻路径
- 宝箱按 `chest_points` 随机生成(掉落逻辑不变)
- 刷怪器使用 `enemy_points` 作为刷怪点(默认 8 个同时在场的上限)

## 18. 角色动画系统(阶段一·多帧行走)

### 18.1 素材与帧来源

- 角色与怪物换用 **0x72 16x16 DungeonTileset II v1.7**(CC-0)的多帧行走素材
- 从官方瓦片图按 `tile_list_v1.7` 裁剪出 4 帧横排条带,存放于 `assets/sprites/`:
  - 玩家(游侠):`player_ranger_idle/run.png`(帧 16×28)
  - 哥布林:`goblin_idle/run.png`(帧 16×16)
  - 骷髅怪:`skeleton_idle/run.png`(帧 16×16)

### 18.2 动画实现

- `tools/generate_sprite_frames.gd` 把条带生成 `assets/sprites/*_frames.tres`(SpriteFrames 资源,含 `idle` / `run` 两个循环动画);场景 AnimatedSprite2D 直接挂载对应 .tres,编辑器即可预览帧
- `scripts/anim_factory.gd`(AnimFactory)统一加载这些 .tres,并登记角色显示缩放;运行时刷怪/回退逻辑与场景共用同一份资源
- 玩家与敌人的 `Visual` 节点由 `Sprite2D` 换成 `AnimatedSprite2D`:
  - `player.gd` / `enemy.gd` 在 `_ready` 中若无 `sprite_frames` 则从 AnimFactory 加载,并播放 `idle`
  - 每帧按移动速度切换动画:`run`(玩家 >20、敌人 >10 速度)否则 `idle`
- 原有程序化动效保留在 `_update_visual_effects` 中,与骨骼/精灵动画叠加:
  - 行走浮动(bob)、朝向 `flip_h`、射箭后坐力、闪避翻滚、椭圆阴影
- 缩放与对齐:玩家 2.5 倍并上移 15px 使脚底对齐碰撞盒;哥布林 2.0 倍、骷髅 2.5 倍

### 18.3 后续规划

- 由 `AnimationPlayer` 统一驱动攻击/受击/施法等新动画(idle/run 已落地为 .tres 资源)
- 新增攻击、翻滚、受击、死亡等动画帧,并接入动作状态机
- 按职业替换角色帧(战士/游侠/法师),AnimFactory 增加角色配置即可

## 19. 装备系统(阶段一·从武器开始)

### 19.1 装备栏位

- 玩家持有 `equipment` 字典,当前含 `weapon` / `armor` 两个栏位
- 按 **I** 打开"背包与装备"面板,实时显示已装备的武器/防具及其属性
- 换装与卸装调用 `player.equip_item(slot, item)` / `player.unequip_item(slot)`,自动触发 `_recalc_stats()` 重算属性并刷新 HUD

### 19.2 装备基础属性:最大生命加成

- 装备统一提供 `max_hp_bonus`(最大生命加成),默认即"装备加血量"
- 有效最大生命 = `base_max_hp`(基础值,升级时 +10)+ 各装备位加成之和
- 当前防具:布衣(防御 +1 · 生命 +15)、木盾(防御 +2 · 生命 +10 · 格挡减伤 80%)

### 19.3 武器:游侠弓箭

| 武器 | 攻击加成 | 特殊效果 |
| --- | --- | --- |
| 生存弓(初始) | +6 | 无 |
| 反曲弓 | +12 | 无 |
| 长弓 | +18 | 无 |
| 精灵弓 | +24 | 箭矢飞行速度 x1.5 |

- 普攻伤害 = 基础攻击力(10)+ 武器攻击加成
- 精灵弓特殊效果通过 `ItemData.arrow_speed_mult` 实现,`player._fire_arrow()` 以 `arrow_speed × 倍率` 发射
- 装备面板提供 4 把弓的"试装"按钮,便于测试伤害与箭速差异

### 19.4 后续规划

- 掉落武器/防具并加入背包拾取流程(当前快捷栏仅装药水)
- 武器词条、元素/特效(火焰箭、穿透、多重箭)与职业专属武器
- 装备强化、耐久与外观变化

## 20. 难度与怪物参数(阶段一)

### 20.1 怪物数据集中管理

- `scripts/enemy_data.gd`(EnemyData)是怪物参数**唯一数据源**:固定敌人由 `main.gd` 套用、刷怪器由 `spawner.gd` 套用,共用 `EnemyData.apply_to()`
- 新增怪物类型只需在 `EnemyData.TYPES` 登记,生成碰撞/动画/缩放自动跟随

### 20.2 当前难度(较初版上调)

| 项目 | 哥布林 | 骷髅怪 |
| --- | --- | --- |

| 移速 / 追击 | 70 / 110 → 80 / 140 | 45 / 80 → 55 / 105 |

# 0.6 三层关卡与 Boss 顺序

实施日期：2026-10-21。四柱守望者改为第一层 Boss，新增第三层白骨庭院与法师终战。第二层几何与原物理验收保持兼容。

## 第一层：守望者的封印庭

入口补给庭、双入口断旗交战厅与封印侧室继续保留。侧室东出口改为沿交战厅东墙向北折返，**在守望者房门西侧与主线合流**，不再从 Boss 房西南单独进入。

- Boss 房仍为 `Rect2(1664,256,736,608)`，Boss `(2048,480)`，楼梯 `(2288,768)`。
- 单一封门 `Rect2(1632,416,32,192)` 完全截断主线和奖励支线，避免破盾阶段退到门外。
- 移除 Boss 房内长掩体和静态碰撞柱；原深井移到房外 `(1888,1024,224,160)`。完整矩形场地为四根移动飞柱留出射击与闪避空间。
- 四个低对比地面纹章围绕房间中心设置，提示石柱机制；纹章没有碰撞。

## 第二层：井缘圣所

沿用 0.5 的交错射手外廊、冲锋祈祷室与井南环路。Boss 房 `Rect2(1536,864,864,608)`，Boss `(2016,1152)`，门 `Rect2(1504,864,32,192)`。本次不改变第二层地形及怪物位置。

## 第三层：失名者的白骨庭

空间由西南的升降台向东北王座爬升，改变前两层从左向右推进的空间节奏。采用低饱和灰紫地面、紫色魂灯、白骨肋纹与终战星环，让新层有独立地标。

| 房间 | 几何 | 玩法目的 |
|---|---|---|
| 余烬升降台 | `(96,992,576,512)` | 安全整理装备、领取本层首箱 |
| 白骨回庭 | `(832,736,736,640)` | 中央实体深井分隔两条推进弧线，掩体切断射线；持盾、织骨者与幽魂混编 |
| 缚星王座 | `(1792,192,896,768)` | 宽敞、无静态柱或内部掩体的法师终战场 |
| 失名者骨库 · 可选 | `(960,1536,576,256)` | 额外宝箱由持盾、幽魂和冲锋者守卫；西出口回到庭院入口形成环路 |

主线穿过骨庭南弧，再沿井东侧向北进入王座。可选骨库从骨庭南侧进入，回路落在骨庭西入口；两条线路最终经过同一个王座门。

- 出生点 `(288,1248)`；首箱 `(544,1120)`；可选箱 `(1216,1664)`。
- 中央井 `Rect2(1120,928,160,224)` 有实体碰撞，地面路径不穿井。
- 王座门 `Rect2(1760,768,32,192)`；Boss `(2240,576)`；出口 `(2560,320)`。
- 八个普通敌人分配为骨庭三名、骨库三名、王座两名，使用 `shieldbearer`、`bone_weaver`、`wisp`、`charger`。
- 房间数组继续为主房 `[0..2]`、支房 `[3]`；`enemy_positions`、`enemy_rooms`、`enemy_roles` 长度一致，外部查询 API 沿用。

## 已完成的几何验证

1. 原 `tools/test_mvp_layout.gd`：第一、第二层真实 26×26 玩家碰撞盒通路、可跳过支线、跨房攻击隔离和换层清理全部通过。日志 `_test/layout-v06-agent.log`。
2. 临时独立实验 `_test/test_layout_v06_agent.gd`：直接实例化世界，不依赖正在集成的新 Boss/怪物脚本；用实际物理碰撞和 16px 采样确认第一、第三层首箱、支箱、Boss 与出口均可达，跳过侧房仍可推进。
3. 对第一、第三层加入与 `boss_gate_rect` 相同的实体门后，从出生点洪泛均无法到达 Boss，验证主路与侧路都被封闭。日志 `_test/layout-third-v06-agent.log`。

上述验证覆盖几何和封门；第三层新敌人、法师技能、三层完整通关和导出包属于主功能集成验收。

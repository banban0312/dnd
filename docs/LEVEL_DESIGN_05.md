# 0.5 关卡实施：双入口与绕井抉择

实施日期：2026-10-21。范围：保留两层、每层三间主房和一间可选侧室、八个普通敌人与一个精英/Boss；通过路线和敌人职责产生变化。

## 第一层：选择进场方向，再学会绕掩体

- **入口补给庭**：保留首箱与安全选弓空间。出口分成北门和南门，分别进入交战厅的上下边。
- **断旗交战厅**：中央竖向长掩体阻断直线射击；近战、冲锋、远程各一。北路能接近远程，南路给冲锋更长预警距离。玩家可绕掩体换边，迫使射手重新找视线。
- **封印侧室**：从交战厅南面进入，由近战、射手、冲锋三种职责守住额外宝箱。取得奖励后，经东面的侧廊从守卫厅西南重新加入主线，形成真正的双出口回路。
- **绞盘守卫厅**：直行主门从西面进入，侧路从西南进入。西南竖向掩体提供切断远程视线的短暂停顿；场内冲锋与射手配合精英形成上一房的组合考试。井口与楼梯仍在东南，井沿有实体碰撞。

主线可跳过侧室。选择侧路要多打一组敌人，回报为现有可选宝箱及从另一角度进入精英厅，无额外刷怪。

## 第二层：上路对射，下路冒险，两路合流

- **落井平台**：保留安全整备箱。东出口通向射手外廊；南出口通往可选奖励支线。
- **断桥外廊**：两座交错的长掩体分别接上墙和下墙，要求先走下方，再切回上方，不再是从门口一条直线射到底。两个射手与一个近战构成慢推进的视线战。
- **遗骨祈祷室**：两名冲锋敌人与一名近战，围绕中央掩体打节奏战。额外宝箱仍在房内；东南出口向南再向东绕过深井，接入圣所西面的共同入口。
- **深井与回廊**：井从装饰升级为实体不可通行区域。下路走廊经过井南侧，上路走廊经过井东侧，两条路径在 Boss 门前合流。地面青色点状镶嵌标明下路转角，避免路线尽头感。
- **井环圣所**：完整保留 `Rect2(1536,864,864,608)` 平台，Boss 位于 `(2016,1152)`，门为 `Rect2(1504,864,32,192)`。移除原平台边缘碰撞柱，提供完整回旋和闪避空间；四个地面纹章提示四柱机制，与移动目标不产生静态碰撞。

两层继续使用原房间名、`rooms[0..3]`、`room_at()`、`is_walkable()`、`route_points` 和箱子规则。新增 `enemy_roles` 与 `enemy_positions` 一一对应，只使用 `melee`、`ranged`、`charger`；`enemy_rooms` 长度对应一致。

## 验证

执行 `tools/test_mvp_layout.gd`，日志 `_test/layout-v05-agent.log`：

- 两层实际 26×26 玩家碰撞盒可达首箱、侧室箱、精英/Boss、楼梯。
- 不进入可选房也能到达精英/Boss 和出口。
- 换层清理、未受击且未进入原始察觉范围时跨房不主动拉怪、墙体阻挡攻击与穿透箭全部通过。追加反馈后受击会建立持续仇恨并允许普通怪跨房追击，另由战斗测试验证。
- `is_walkable()` 同步扣除掩体与井区域，视觉掩体、地图查询和实体碰撞一致。

战斗平衡与四柱 Boss 的回归由功能集成测试覆盖；此关卡验证不声称已完成人类试玩平衡。

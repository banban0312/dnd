# deeper and deeper：旧三层开发规划（已归档）

> 2026-10-21归档。以下记录针对更早的旧Demo，部分问题已由两层MVP解决。三层、四遗物和层间续玩均不属于当前排期。请执行[当前两周计划](SHORT_TERM_ROADMAP.md)。以下保留原文以便追溯。

## 一句话定位

一款以弓箭手为主角的俯视角像素地牢游戏。你带着有限补给下降，在每层出口决定带走战利品，还是押上本局收获，换取更深处的能力与秘密。

推荐中文副标题：**深处仍有深处**。英文名称保持小写 `deeper and deeper`；菜单主标可以分两行排列，让第二个 deeper 下沉一行，配合贯穿画面的竖井，形成记忆点。

本轮目标是 12–18 分钟的完整试玩切片，不是完整商业版。以下玩法、时长与数值都是待实测的设计目标。

## 现有作品的真实起点

| 已有内容 | 当前限制 | 近期处理 |
|---|---|---|
| 射击、翻滚、格挡、Q 连射、E 加速 | 反馈较多，但普通敌人与 Boss 主要靠追逐和接触伤害 | 增加明确前摇和可躲避攻击，不先加职业 |
| 3×3 随机房间与障碍 | 固定小怪依次取点，集中于少数房间 | 先按房间职责分配内容，再随机位置 |
| 中央 Boss 与出生点 | 出生紧邻 Boss 区域，开局即显示 Boss 血条 | 出生移至外围，Boss 成为终层高潮 |
| 装备、背包、等级、两项技能 | 成长主要靠数值，更换装备的打法差异有限 | 用少量行为遗物形成两个打法方向 |
| 存档、死亡复活、调试刷怪 | 偏测试沙盒；缺少一局边界 | 改为明确冒险状态、有限遭遇、结算与重开 |
| 像素环境、动画、粒子、合成声音 | 风格细节与 UI 信息层级不统一 | 统一表现，减少同时抢眼的元素 |

代码依据：main.gd 的 _setup_world/_place_fixed_enemies/_on_player_died，map_generator.gd 的 _compute_points，boss.gd 的追逐与接触伤害，HUD 的固定布局，以及 save_manager.gd 的当前存档路径。

## 三层怎样真正不同

保留 3×3 房间骨架，不另造一个复杂生成器。每层控制为 4–5 个重点遭遇或选择房；连接空间短而有辨识度，避免为铺满地图而加怪。

| 深度 | 主题与目标 | 主要变化 | 建议时长 |
|---|---|---|---|
| I：封土回廊 | 学会观察并建立信心 | 安全出生、单敌教学、宽阔战场；守门精英解锁出口 | 3–4 分钟 |
| II：无灯圣所 | 迫使玩家调整走位 | 哥布林与骷髅混编、交错掩体；可绕开的高收益精英房 | 4–5 分钟 |
| III：余烬之井 | 检验本局打法 | 缩短探索、最后一次补给取舍、现有巨魔的终战 | 4–6 分钟 |

加上入口引导、层间选择和结算，目标总时长 12–18 分钟。不要把每层全部房间都做成必须清空的竞技场。

第一、二层的必经守门精英复用现有敌人外形，以体型、轮廓标记与攻击节奏区分；不做独立新 Boss。第二层额外精英房不参与出口解锁，玩家可以跳过。终层 Boss 放在远离出生的房间，进入后才出现血条。

前两层守门战后出口可用，不要求清空全图。出口菜单只问一个问题：**撤离，还是继续下降？** 撤离旁展示当前可记录收益；下降旁明确下一层风险与奖励。不能依靠隐藏惩罚制造紧张感。

## 深度来自三个决定

1. **战斗决定**：继续射击，还是留出空间躲避前摇？
2. **路线决定**：绕开危险精英，还是消耗补给换取更高战利品价值？
3. **冒险决定**：现在撤离，还是带着当前能力继续下降？

不再额外添加氧气、饥饿、耐久、理智或整层倒计时。首版资源压力由当前生命、法力和药水承担。

### 四个遗物，两次选择

第一、二层出口各提供两项未持有遗物，选择一项；先选择遗物，再决定撤离或下潜。数量很少，但每项需要说明效果与代价。

| 遗物 | 初始设计值，待调优 | 行为意义 |
|---|---|---|
| 破骨钉 | 箭穿透一个敌人，单箭伤害降低 15% | 主动引导敌人排成直线，适合清群 |
| 分叉羽 | Q 多发一箭，Q 法力消耗增加 5 | 一次技能覆盖更多目标，与穿透组合 |
| 猎手印 | 同一敌人连续命中第三箭时，该箭增伤 50%；换目标重置 | 保持目标，适合精英与 Boss |
| 静息弦 | E 期间射击命中恢复少量法力，每次射击最多触发一次 | 支持持续点杀；法力恢复必须低于施法成本，避免无限循环 |

本轮只承诺两种雏形：穿透清群、集中点杀。遗物不设品质、不升级、不组成庞大随机词缀库。若 D6 超时，静息弦降级为 E 固定减耗，保留穿透与连续命中的操作区别。原有技能升级保留，但不扩技能树。

箭穿透需要记录本箭已命中目标，避免同一敌人重复受伤；遗物必须在新局清空。连续命中、箭速、Q 多箭与恢复之间都要检查重复触发。

### 失败与收益

- 生命归零即结束本局，展示到达深度、耗时、击杀、遗物与战利品价值；未撤离的价值作废。
- 撤离与通关把本局有效价值写入最佳记录；首版不引入仓库和商店。
- 失败不扣除历史最佳，不用永久数值成长补偿难度。
- 结束界面能直接重开；从头到尾无需开发面板。
- 暂定分值：普通宝箱 10、可选精英奖励 30，层间结算倍率 I 为 1.0、II 为 1.5、III 为 2.0；先验证取舍是否成立，再调具体数值。

## 美术方向：冷石里的最后一点火

我建议保留像素风，做克制的暗色地牢。角色、可交互物、攻击预警必须比背景更清楚。这里的精良来自统一，而不是铺满光效。

| 元素 | 规范 |
|---|---|
| 基础色板 | 深墨 #14151D、冷石 #343845、骨白 #D8D2C4、烛金 #D6A34A、深渊红 #AD484B |
| 三层表现 | 第一层暖火照冷石；第二层冷青反光与更少火源；第三层骨白石面、深红裂缝 |
| 角色 | 保留现有动画；统一视觉脚底基线和占屏比例，nearest 采样，避免像素密度差异过大 |
| 墙与地面 | 压低地面纹理对比；墙脚增加接触阴影；仅补少量裂缝、烛台、碎骨、深井口 |
| 光照 | 基础环境保持可辨认；少量暖光引导出口，避免全屏发黑；先不做复杂动态阴影 |
| 打击表现 | 统一命中闪白、轻微后坐与低幅震动；Boss 重击才使用更强反馈，支持关闭震动/闪烁 |
| 危险提示 | 红色轮廓加扇形/圆环及明确蓄力动作；不能只用颜色区分危险 |
| UI | 薄边、留白、低对比底板；HUD 保留生命/法力、Q/E、药水、层数与目标；完整属性放入背包 |
| 菜单 | 下沉式标题、竖井背景、小范围尘埃；先出静态精致版，再考虑动态背景 |
| 声音 | 弓弦、受击、翻滚、出口确认各有清楚层级；深层减少环境声，Boss 前留短暂安静 |

像素角色可以踩在柔和光照中，但字体与 UI 不必伪装成低分辨率。统一一个清楚的中文字体；不在同屏混用多套装饰字体。不同分辨率下检查 HUD，不用新增美术掩盖布局溢出。

本期不承诺整套角色重绘、全新动画库或手绘大型插画。需要补的资产优先是出口、遗物图标、危险提示与少量环境装饰。生成概念图只可作为参考，不能直接代替可用的 SpriteFrames 或精确 UI。

## 10 个工作日进度

预算约 80 小时：D1–D8 每天约 8 小时；D9–D10 的 16 小时专门用于试玩、修复、交付和超时缓冲。需要新框架或整体换资产时，这个预算不成立。

| 日程 | 交付物 | 当日验收 |
|---|---|---|
| D1 | 出生与房间职责；有限遭遇；隐藏默认调试入口；明确本局目标 | 30 秒内接敌但不会出生贴 Boss；至少三个房间有合理分布的内容 |
| D2 | 冒险状态、楼层计数、出口；当前层内容统一释放与重建 | 连续换层五次，没有旧怪、掉落、宝箱或箭残留，没有重复信号回调 |
| D3 | 撤离/死亡/通关结算与重开；新旧存档隔离 | 能走完整灰盒流程，死亡不会随机门口复活；原存档不受损 |
| D4 | 小怪攻击预警、Boss 两招与反馈层级 | 哥布林近身挥击、骷髅蓄力突进、Boss 扇形重击/圆环震地均能看懂并躲避 |
| D5 | 四遗物与两次选择；奖励描述 | 同一存档基础能玩出清群与点杀倾向；无重复命中、重复奖励、法力永动 |
| D6 | 三层内容配置、可选精英房、治疗与掉落初调 | 第二层改变站位策略，第三层有短准备与终战；能控制目标时长 |
| D7 | 环境色板、灯光、接触阴影、出口与预警统一 | 一张正常战斗截图有明确视觉焦点；最暗区域仍能看清碰撞边界 |
| D8 | 主菜单/HUD/遗物选择/结算统一；整理音量层级 | 1280×720 与 1920×1080 均不遮挡关键提示；调试 UI 不进入普通流程 |
| D9 | 三位新玩家试玩，记录迷路、误伤、选择与结束原因 | 完成观察记录；优先修流程阻塞和不可读伤害，不新增系统 |
| D10 | 回归修复、Windows 包、30–60 秒实机展示与简短说明 | 新目录首次启动、三种结算、续玩、重复重开均通过 |

**D3 检查点**：还不能走完灰盒流程，缩为两层，把第三层 Boss 提前放入第二层；不继续堆内容。

**D6 检查点**：若攻击或遗物仍不稳定，冻结额外装饰与遗物复杂效果；D7–D8 优先帮助玩家看懂现有玩法。

## 实现顺序与技术风险

1. 将冒险状态集中管理：菜单、战斗、层间选择、结算。AI 面板、背包和层间菜单不能各自解除别人的暂停。
2. 处理世界生命周期。当前 Main 动态创建的 Boss/宝箱/掉落与 Spawner 的敌人不在 MapGenerator 的清理范围，不能重复调用 _setup_world 充当换层。固定敌人也不能一直依赖 $Goblin1 等四个节点。
3. 生成与清理之间保留安全时机，清除在途箭和延迟回调；换层只保留 Player 的规定状态，重置目标引用、Boss 血条和房间奖励。
4. 先完成灰盒局流程，接着攻击可读性，再接遗物触发点，最后统一视觉。避免同时重写整个 Player/Enemy/HUD。
5. 新冒险存档写入 user:// 独立版本，详见 DECISIONS。每层生成时要保留随机种子和入层角色快照，不只存当前层数字。
6. 不增加外部服务依赖；未配置 DeepSeek Key 或离线时仍能完整游玩。

## 最终验收清单

### 工程验证

- 现有启动测试继续通过，并扩展为楼层切换、三种结算、重开后的遗物清空、存档失效与恢复。
- 固定至少 10 个种子检查：入口到出口可达、出生不重叠、精英奖励只发一次；随机布局不满足条件时有安全回退。
- 下潜五次/重开十次后，无明显节点持续累积，无已释放对象引用或重复信号报错。
- 全新缓存导入与可执行包必须在可写目录验证；此前执行环境的 safe-save 权限错误不算通过。
- 目标机器记录为本机 Intel Iris Xe；1280×720 目标 60fps，正常战斗 95% 帧不超过约 20ms。实际测量不达标就先减粒子与光源。
- 不复制真实 API Key、私人配置或开发存档到发布包；离线完成一局。

### 体验验证

让三名未玩过项目的人各试玩一局，不提前解释所有机制：

- 至少两人一分钟内能开始探索，并知道当前目标。
- 至少两人能指出上下层的行为差异，以及自己的遗物选择理由。
- 至少两人能说明撤离或继续下降的原因；若所有人无条件继续，重新调风险/奖励。
- 死亡者能说明主要败因；看不到预警的伤害优先修复。
- 常规路线连续空跑目标不超过 15 秒；整局目标 12–18 分钟，超出就先缩短连接与必经战斗。
- 产出一段 90 秒无开发面板的连续游玩录屏，包含探索、可读战斗和一次明确选择。

## 后续只在切片成立后考虑

优先扩展房间组合、遗物相互作用和敌人配合；之后再讨论新职业、长期解锁与更多层数。本轮不把它们塞进排期，也不把“无限层数”当作纵向深度。

`manifest.json` 记录相对于仓库根目录的包路径、精确字节数与 SHA256。`pending` 表示尚未生成，不能当作已可分发版本。v0.6 已生成并通过12组回归、PCK和全新解压目录的本机原生运行验证，第二台机器仍待验收。

v0.4、v0.5 是从 `_test/build/` 原包复制归档，两份复制品均已与原文件校验一致。原包继续保留。归档日期为 2026-10-21，不代表历史版本的最初发布日期。

发送给朋友时，选择对应版本目录中的完整 ZIP；对方使用 Windows 64 位电脑，完整解压后启动 EXE，并保留同目录 PCK 文件。

ZIP、EXE、PCK 为本地构建产物，已由 `.gitignore` 排除。仓库提交此说明、版本目录占位文件与清单；仅克隆代码仓库不会下载试玩包。

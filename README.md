# Darker and Darker(dnd)— Godot 4 阶段一 Demo(游侠)

西幻暗黑风格的地牢冒险游戏(2D 俯视角),当前为阶段一可玩 Demo。完整设计见 [docs/游戏开发文档.md](docs/游戏开发文档.md)。

## 玩法

- 玩家职业:**游侠**(战士搁置)
- 探索箱庭地牢,击杀哥布林与骷髅怪;敌人固定位置巡逻,**进入仇恨范围后会追着你索敌**
- 左键射箭(小方块占位箭矢),命中敌人造成伤害
- Q **三连发**:快速连射 3 支箭;E **拉弓加速**:3 秒内攻击频率大幅提升
- 打开宝箱与击杀敌人获得**概率掉落**:红药水 / 蓝药水(进入 3 格快捷栏,快捷栏仅用于掉落消耗品)
- 药水直接回满对应属性:红药水回满生命,蓝药水回满蓝量
- 击杀与开箱获得经验,升级提升属性并获得技能点(K 面板分配)
- 死亡回到最近存档点(触碰紫色存档点即记录,**同时写入本地存档**)
- **本地存档**:触碰存档点或点"手动存档"按钮即保存(角色等级/技能/装备/快捷栏/地图种子),启动时有"继续游戏/新游戏"菜单
- **战斗反馈**:伤害飘字、敌人死亡白闪淡出动画、箭矢拖尾粒子、受击闪白
- **音效**:程序化合成音效(射箭/命中/受击/格挡/闪避/升级/开箱/拾取/死亡,无需外部素材)
- **中心 Boss·独眼巨魔**:镇守中央房间;仅进入中央区域引发仇恨,**永不离场**;自带动态待机(呼吸浮动/独眼发光/暗影粒子),顶部 Boss 血条,死亡固定掉落药水

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标左键 | 射箭(有攻击间隔,不消耗蓝量) |
| 鼠标右键 | 格挡(通用减伤) |
| Shift | 翻滚闪避(短暂无敌) |
| Q | 三连发箭(快速连射 3 支) |
| E | 拉弓加速(3 秒内攻击频率提升) |
| F | 打开宝箱 |
| 1 / 2 / 3 | 使用快捷栏药水 |
| I | 背包与装备面板 |
| K | 技能面板(分配技能点) |
| T | 测试工具:刷怪 开/关 |
| R | 重新开始 |

## 测试工具

画面右上角有"测试工具"面板:

- **刷怪开关**:按钮点击或按 T 键,开启后每 3 秒在刷新点生成敌人(最多 8 个同时在场)
- **无限蓝+无CD**:按钮点击或按 U 键,测试用作弊开关
- **手动存档**:随时把当前进度写入本地存档(存档点触碰也会自动保存)
- 面板实时显示场上敌人数量

## 存档系统

- 存档位置:`res://save/save.cfg`(即项目目录 `save/` 下,开发期可直接查看/删除)
- 注意:导出发布后 `res://` 为只读,正式版需把 `save_manager.gd` 的 `SAVE_PATH` 改回 `user://` 或 OS 可写路径
- 保存内容:角色(等级/经验/技能点/技能等级/基础属性/当前 HP·MP)、装备(武器/防具)、快捷栏药水、地图随机种子、重生点坐标
- 触发时机:触碰紫色存档点自动保存;测试工具"手动存档"按钮随时保存
- 启动流程:有存档时弹出"继续游戏 / 新游戏"菜单(暂停等待选择);继续游戏恢复角色并复现同一张地图(同种子)
- 按 R 重开场景,当前进度保留

## 运行

用 Godot 4.7 打开本文件夹,按 F5 运行 `res://main.tscn`。

命令行冒烟测试:


```
## 地图系统

- **大型地图**:由 3×3 固定大小箱庭(960×720)组成的 2880×2160 地牢,玩家出生在中央房间
- **房间连接**:相邻房间之间的墙随机开口(门口),保证整个地牢全连通
- **随机路障**:每个房间随机生成 2~5 个路障(石柱 / 横竖墙块),自动避开门洞通道与出生点
- **生成器**:`scripts/map_generator.gd`,房间尺寸、网格行列数、路障数量、随机种子均可在编辑器里配置(`rng_seed` 填固定值可复现同一张图,0 为每次随机)
- 玩家有摄像机跟随并限制在地图范围内;宝箱、敌人出生点、存档点均由生成器分配到安全位置

## 角色动效

- **行走浮动**:移动时角色上下浮动并轻微倾斜,静止时平滑回正
- **朝向翻转**:根据移动方向(静止时根据鼠标)左右镜像,不再是一张死板的贴图平移
- **射箭后坐力**:射击瞬间角色向反方向轻微后仰,随箭头飞出回正
- **闪避翻滚**:Shift 闪避时角色旋转一圈,做出翻滚感
- **地面阴影**:玩家与所有敌人脚下都有椭圆阴影,增强立体感(素材 `assets/sprites/shadow.png`,程序生成)
- 敌人同样有行走浮动与朝向翻转
```
